# Portafolio personal — Angelo Pastene Acevedo

Portafolio desarrollado en React + Bootstrap para la Evaluación Formativa 2 de
DSY1104 Desarrollo Fullstack II (Duoc UC, sede Maipú).

> Documentación completa (instalación, pruebas, capturas y despliegue) en construcción.

## Comandos

| Comando | Qué hace |
|---|---|
| `npm install` | Instala las dependencias |
| `npm run dev` | Levanta el servidor de desarrollo |
| `npm test` | Ejecuta las pruebas Jasmine con Karma y genera la cobertura |
